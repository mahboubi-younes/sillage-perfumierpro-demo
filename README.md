# Sillage - Guest Demo / Experience Mode

Isolated portfolio demonstration of Sillage - PerfumierPro.

- Opens directly with fictional seeded data
- Local browser persistence and resettable demo state
- POS, products, inventory, customers, loyalty, sales history and analytics workflows
- No commercial activation tooling, passkeys, private keys, credentials or production data

This is not the commercial licensed Sillage application. Its activation boundary remains private and unchanged.
