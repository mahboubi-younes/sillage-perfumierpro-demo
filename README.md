# Sillage - PerfumierPro Demo

An activation-gated web demonstration of **Sillage**, a point-of-sale and
operations system for perfume-shop owners who need to manage sales, stock,
customers, and reporting in one workflow.

## Who it is for

Independent perfume stores and retail teams that want a tailored system for
daily selling, inventory control, and customer loyalty.

## Features

- Point-of-sale flow with barcode support and custom perfume sizes
- Inventory monitoring, pricing, and low-stock visibility
- Customer records and loyalty tiers
- Sales history, analytics, accounting, and operational reporting
- Role-aware screens and a local activation gate

## Local use

This repository intentionally contains the browser-ready demonstration build,
not the private development source or owner activation tooling. To preview it,
serve this folder with any static web server.
