# Manuel d'Utilisation - Sillage (Édition Premium)

Bienvenue dans **Sillage**, votre solution de gestion spécialisée pour la Haute Parfumerie. Ce manuel vous aidera à démarrer rapidement avec votre logiciel.

---

## 1. Démarrage Rapide
Pour lancer votre logiciel :
1.  Ouvrez le dossier **`Sillage_Client_Distribution`**.
2.  Faites un double-clic sur le raccourci **`Sillage - PerfumierPro`** (icône Sillage).
3.  Le logiciel s'ouvrira automatiquement dans votre navigateur web habituel.

> **Note :** Si la page reste noire, appuyez simplement sur la touche **F5** de votre clavier pour rafraîchir la page.

---

## 2. Connexion
Vous avez deux types de comptes par défaut :
*   **Administrateur (Gérant) :** 
    *   Nom d'utilisateur : `admin`
    *   Mot de passe : `123`
*   **Vendeur :**
    *   Nom d'utilisateur : `vendeur`
    *   Mot de passe : `123`

---

## 3. Configuration de la Sécurité (Telegram)
Pour protéger votre compte et réinitialiser votre mot de passe en cas d'oubli :
1.  Connectez-vous avec le compte **Admin**.
2.  Allez dans **Paramètres > Telegram Bot**.
3.  Entrez votre `Bot Token` (obtenu via @BotFather) et votre `Chat ID`.
4.  Cliquez sur **Enregistrer et Verrouiller**.
    *   *Une fois cette étape effectuée, vous pourrez réinitialiser votre mot de passe en cas d'oubli en cliquant sur le lien "Mot de passe oublié ?" sur l'écran de connexion.*

---

## 4. Gestion de l'Inventaire
*   **Ajout d'un Parfum :** Cliquez sur "+ Nouveau Parfum", remplissez les détails, et assignez-lui une catégorie.
*   **Modification :** Cliquez sur l'icône ✏️ dans la liste des produits pour ajuster le prix ou le stock.
*   **Visibilité :** Les listes déroulantes (Catégories) ont été optimisées pour une meilleure lisibilité.

---

## 5. Analytiques
L'onglet **Analytiques** vous offre une vue en temps réel de votre activité :
*   **Chiffre d'Affaires :** Suivi global de vos ventes.
*   **Performances :** Identifiez vos meilleurs produits et vos catégories les plus vendues.
*   **Filtres :** Utilisez les boutons en haut à droite pour basculer entre les vues (7 jours, 30 jours, 1 an).

---

## 6. Sauvegarde et Sécurité
**Important :** Vos données sont stockées sur votre ordinateur.
*   Allez dans **Paramètres > Sauvegarde**.
*   **Export JSON :** Téléchargez une sauvegarde complète de votre base de données régulièrement (sur clé USB).
*   **Restauration :** Utilisez le bouton d'importation pour restaurer vos données sur un nouveau PC si nécessaire.

---

## 7. Dépannage
*   **Le logiciel ne s'ouvre pas :** Assurez-vous que Node.js est installé sur votre machine.
*   **Page noire :** Appuyez sur **F5** ou videz le cache de votre navigateur (Ctrl + Shift + Delete).
*   **Erreur de connexion :** Vérifiez que vous avez bien saisi votre nom d'utilisateur (pas d'email).

*Pour toute question technique, veuillez contacter le support Sillage Technologies.*
